CARGO ONE — запуск на своём компьютере (без GitHub и без интернета для самого сайта)

1. Установите Node.js (один раз): https://nodejs.org — кнопка LTS. Нужна версия 22.13 или новее.
2. Распакуйте этот архив в любую папку.
3. Windows: дважды нажмите «ЗАПУСК-Windows.bat».
   Mac: правой кнопкой по «ЗАПУСК-Mac.command» → Открыть (первый раз macOS спросит разрешение).
4. Через несколько секунд откроется браузер: http://localhost:3000
   Окно с чёрным текстом не закрывайте — это и есть сервер. Закрыли окно = сайт выключился.
5. Ничего нажимать не нужно: при первом запуске сайт САМ загрузит реальные товары AliExpress
   (≈700 штук, 17 вызовов OT Commerce, 1–3 минуты) и спрячет выдуманные демо-товары.
   Машины получат реальные фото моделей (Wikimedia Commons, с указанием автора).
   Вход админом (если нужно): admin@cargo.one / demo1234

Товары и фото сохраняются в папке «data» рядом с этим файлом.
При первом запуске программа попросит ключ OT Commerce и сохранит его в файл .env.
